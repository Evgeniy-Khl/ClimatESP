# Інструкція з налаштування Telegram-бота для контролера «Клімат-5.25»

---

### Крок 1. Створення власного Telegram-бота через @BotFather

1. Відкрийте додаток **Telegram**.
2. У рядку пошуку введіть **`@BotFather`** (офіційний бот Telegram із синьою галочкою верифікації) та перейдіть у діалог із ним.
3. Натисніть кнопку **«Розпочати»** (або надішліть команду `/start`).
4. Надішліть команду:`/newbot`
5. **Вкажіть видиме ім'я бота** (як він відображатиметься у списку чатів), наприклад:`Клімат Контролер`
6. **Вкажіть системне ім'я (username)**: воно має бути унікальним і обов'язково закінчуватися на `bot` або `_bot`, наприклад:`my_climat_525_bot`
7. Після успішного створення `@BotFather` надішле повідомлення з **API-токеном**:
`Use this token to access the HTTP API:   7123456789:AAFlkJsdlfkj234_sdf98sdfEXAMPLE`
8. **Скопіюйте цей токен** — це значення поля `botToken`.

---

### Крок 2. Налаштування меню команд (/start, /stop, /status)

Щоб у вашому боті в лівому нижньому кутку з'явилася кнопка **«Меню»** зі швидким доступом до команд:

1. У діалозі з **`@BotFather`** надішліть команду:`/setcommands`
2. Оберіть вашого щойно створеного бота зі списку (натисніть на кнопку з його юзернеймом або надішліть `@my_climat_525_bot`).
3. Надішліть наступний список команд **одним повідомленням**:
	`
	start - Увімкнути таймер (у разовому режимі)
	stop - Вимкнути таймер (у разовому режимі)
	status - Поточний стан приладу
   `
4. `@BotFather` відповість повідомленням: *«Success! Command list updated.»*. Меню команд створено.

---

### Крок 3. Отримання вашого персонального Telegram Chat ID

Контролер надсилає повідомлення та приймає команди **виключно від вашого акаунту** (захист від несанкціонованого доступу сторонніх осіб).

1. У рядку пошуку Telegram знайдіть бота **`@userinfobot`** (або `@myidbot`) та відкрийте його.
2. Натисніть **«Розпочати»** (`/start`).
3. Бот надішле повідомлення з вашими даними:`Id: 123456789 First: Іван ...`
4. **Скопіюйте число** навпроти рядка **`Id:`** (наприклад, `123456789`) — це значення поля `chatID`.

> [!IMPORTANT]
> **Обов'язкова дія:** перейдіть за посиланням на вашого власного створеного бота (наприклад, `t.me/my_climat_525_bot`) та натисніть кнопку **«Розпочати»** (`/start`). Політика Telegram забороняє ботам надсилати перші повідомлення користувачам, доки користувач сам не відкрив діалог.

---

### Крок 4. Заповнення налаштувань у веб-інтерфейсі (`setup.html`)

1. Підключіться до контролера через браузер за його IP-адресою (наприклад, `http://192.168.1.208` або `http://192.168.4.1`).
2. На головній сторінці натисніть кнопку **«НАЛАШТУВАННЯ»**.
3. Перейдіть на останню вкладку **«Telegram»**:
   * **Telegram Bot Token (від BotFather):** вставте скопійований у Кроці 1 токен (наприклад, `7123456789:AAFlkJsdlfkj234_sdf98sdfEXAMPLE`).
   * **Telegram Chat ID (ID чату):** вставте ваш числовий ID з Кроку 3 (наприклад, `123456789`).
4. Переконайтеся, що на вкладці **«Wi-Fi»** прилад налаштований на підключення до домашнього роутера (інтернет необхідний для зв'язку з серверами Telegram).
5. Натисніть кнопку **«ЗБЕРІГТИ»** внизу форми.

---

### Крок 5. Перевірка роботи та взаємодія

1. **Стартове сповіщення:**
   При запуску та підключенні до домашнього роутера прилад автоматично надішле вам у Telegram повідомлення:
   `
   Клімат-5.25  №: 1
   IP: 192.168.1.208
   `

2. **Використання команд:**
   * **`/status`** — повертає миттєвий звіт:
     `
     Клімат-5.25  №: 1

     - повітря: 37.8°C
     - продукт: 37.5°C
     - вологість:  55%
     - підігрів: 42%
     - заслінки: 15%
     - таймер: ВИМК (2 год.)
     - помилки: 0
     `
   * **`/start`** — якщо налаштовано разовий таймер (`rotate0 = 0`, `rotate1 > 0`) і реле вимкнене, прилад увімкне силовий вихід таймера, зафіксує час у незалежній пам'яті RTC і відповість: `Таймер увімкнено на X год.`. Якщо реле вже працює, команда буде безпечно проігнорована.
   * **`/stop`** — якщо реле разового таймера увімкнене, вимикає його, очищає мітку часу в RTC і відповідає: `Таймер вимкнено.`.

> [!NOTE]
> Якщо ви перебуваєте у веб-інтерфейсі приладу в браузері, 
контролер тимчасово призупиняє опитування Telegram на час веб-активності (близько 20 секунд) 
для збереження оперативної пам'яті та плавного керування симістором. 
Команди з Telegram обробляються, коли сторінка браузера закрита або екран телефону заблоковано.
